# Bengaluru Home Value

A small Flask web app that serves the trained house price model and a browser form.

## Run locally

Open PowerShell in this folder and run:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Then open <http://127.0.0.1:5000> in your browser.

The app loads `house_price_model.pkl` and `Bengaluru_House_Data_Cleaned.csv` from this folder on startup. Keep the Python/scikit-learn version compatible with the one used to create the pickle. Do not load pickle files from untrusted sources.

## API

- `GET /api/options` returns the dropdown values from the cleaned dataset.
- `GET /api/analytics` returns grouped average listing prices used by the charts.
- `POST /api/predict` accepts JSON fields `area_type`, `availability`, `location`, `total_sqft`, `bhk`, `bath`, and `balcony`; it returns the estimated price in lakh and rupees.
